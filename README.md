## Selected Work

### Hurryline

[`LAVE-AUTO/lavo`](https://github.com/LAVE-AUTO/lavo) · TypeScript · 1,000+ commits

Car wash booking, queue and payment platform serving three audiences: clients who reserve and pay online, partner stations that manage their queue, and administrators who run the marketplace.

Covers the full authentication lifecycle, station onboarding with KYC review, the reservation and queue lifecycle including delays, reschedules, no shows, presence confirmation and upgrades, Stripe Connect payments with tips, reconciliation, disputes, refunds and commission history, notifications by email, push and in app feed, admin analytics and moderation, and scheduled jobs for reminders, reconciliation and compliance.

<sub>Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · next-intl (fr, en) · Stripe Connect · Jest · Playwright · OpenAPI</sub>

### craft-suite

[`craft-suite`](https://github.com/Handsomeboy990/craft-suite) · Shell · 200+ commits

152 skills and 16 agents that hold a coding agent to a professional standard, organised into seven domains. Includes an installer with per domain scopes, a configuration layer so nothing user specific is hardcoded, a structure validation suite, and a local control centre.

<sub>Bash · POSIX shell · GitHub Actions · plugin packaging</sub>

### Curb

[`curb`](https://github.com/Handsomeboy990/curb) · TypeScript

An accessibility remediation agent that takes a React component with defects and returns a reviewable fix. Its point of difference is the measurement: it is scored on whether a person using a screen reader or a keyboard is actually better off afterwards, not on whether an automated scanner stopped complaining. Built against the obligation created by the European Accessibility Act.

<sub>TypeScript · React · WCAG · screen reader and keyboard verification</sub>

### MediTrust

[`MediStack`](https://github.com/Handsomeboy990/MediStack) · TypeScript

Cash desk, billing and stock platform for health centres: patient registration, service billing, payment collection, central warehouse stock tracking and role based dashboards. Built for the MTN Benin and Ministry of Health hackathon, Y'ello Care, 22 to 24 June 2026.

<sub>NestJS · TypeScript · PostgreSQL · Prisma</sub>

### HEMORA

[`BMM`](https://github.com/Handsomeboy990/BMM) · TypeScript

Pan African blood donor management platform connecting volunteer donors to the urgent needs of health facilities, organising donation campaigns and anchoring data integrity on Bitcoin. Built for the Bitcoin Mastermind 2026 hackathon and designed to stay in production beyond the event.

<sub>TypeScript · Next.js · Bitcoin</sub>

### YOWL Community

[`YOWL_COMMUNITY`](https://github.com/Handsomeboy990/YOWL_COMMUNITY) · PHP · 120+ commits

Community platform with reviews, discussions and moderation, built on a Laravel API with a Vue single page front end.

<sub>Laravel 12 · Vue 3 · Tailwind CSS · MySQL</sub>
